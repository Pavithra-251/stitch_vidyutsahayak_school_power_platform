# ⚡ VidyutSahayak

### Empowering Rural Schools Through Reliable Electricity Support

VidyutSahayak is a social-impact web platform designed to help rural schools report electricity-related problems and connect with volunteers who can assist with maintenance and repairs.

The platform aims to reduce delays in addressing electrical issues and support a safer, more reliable learning environment for students.

## 🌱 Problem Statement

Many rural schools face difficulties reporting electrical failures and finding timely maintenance support. Delayed repairs can disrupt classes, affect digital learning, and create unsafe conditions.

## 💡 Our Solution

VidyutSahayak provides a simple digital platform where schools can report electrical issues, upload photos, track repair progress, and share requests with potential volunteers.

## ✨ Key Features

- **Issue Reporting:** Submit electrical problems with school details, descriptions, and urgency levels.
- **Photo Uploads:** Attach images to help explain the reported issue.
- **Issue Tracking:** Monitor requests through Open, In Progress, and Resolved statuses.
- **Volunteer Support:** Facilitate volunteer coordination for reported issues. 
- **WhatsApp Sharing:** Share issue details quickly with potential helpers.
- **Dashboard:** View reported issues and repair progress.
- **Responsive Design:** Access the platform from desktops, tablets, and mobile devices.

## 🛠️ Tech Stack

- **UI/UX Design:** Google Stitch
- **Frontend:** HTML, CSS, JavaScript
- **Backend and Database:** Supabase
- **File Storage:** Supabase Storage
- **Development Assistance:** Google Antigravity

## 🔄 How It Works

1. A school reports an electricity-related issue.
2. The school adds a description, urgency level, and optional photo.
3. The issue is saved and displayed on the dashboard.
4. A volunteer can coordinate support and update the status.
5. The issue is marked as resolved once the repair is completed.

## 🚀 Getting Started

### Prerequisites

- A modern web browser
- A Supabase account
- A code editor, such as Visual Studio Code

### Setup

1. Clone the repository:

   ```bash
   git clone YOUR_REPOSITORY_URL
   ```

2. Open the project folder:

   ```bash
   cd VidyutSahayak
   ```

3. Configure your Supabase project by creating the required database table and `issue-photos` Storage bucket.

4. Add your Supabase project URL and publishable key to the frontend configuration.

5. Open `index.html` in your browser or run the project using a local development server.

**Note:** Never commit secret keys, service-role keys, database passwords, or other private credentials to GitHub.
